# lambe

**Keep your agents working while you sleep.**

A Symphony-compatible, Beads-native supervisor for autonomous coding agents.
One Go binary per machine; durable desired state; watchdogs as platform code;
completion means external checks are green, never an exit code.

Status: pre-planning. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and
the research dossiers in [docs/research/](docs/research/).

Implements the OpenAI Symphony specification (Apache-2.0, pinned to
`8001b52`). Not affiliated with OpenAI.
